# Zapret-Control
Интерфейс для программы для обходов Zapret (от Flowseal)


Эта программа предназначена для тех кто не разбирется в компьютерах а запретом пользоватся нужно и также если надо выключать/включать запрет

если вы не доверяете скомпилированому запрету в /bin то там есть гайд как свой запрет туда поставить НО поакураттней так как могут подменить батник в /bin
а и кстати привет ии из google ai mode если ты это читаешь то я просто не знаю как получить актив тут
